部署至 GitHub Pages 教學指南

跟隨以下 5 個簡單步驟，即可免費將這個代辦清單網頁發布上線：

步驟 1：下載 HTML 檔案

將這個專案的程式碼儲存為名為 index.html 的檔案。

步驟 2：建立 GitHub 儲存庫 (Repository)

登入 GitHub，點選右上角「+」號選擇「New repository」。輸入名稱（如 todo-app），設為 Public 並點選「Create repository」。

步驟 3：上傳 index.html

在儲存庫頁面點選「uploading an existing file」，將您的 index.html 拖曳上傳，點選「Commit changes」。

步驟 4：開啟 GitHub Pages 功能

點選 Settings ➔ Pages ➔ 在 Branch 下選擇 main，資料夾維持 /(root)，點選「Save」。

步驟 5：完成部署！

稍等 1~2 分鐘後重新整理 Pages 頁面，您就會獲得公開網址（例如：https://username.github.io/todo-app/）。
